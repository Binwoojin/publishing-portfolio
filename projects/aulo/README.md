# Aulo Cafe Service

Aulo는 사용자의 목적에 따라 좌석을 추천하고,
카페 좌석 예약과 음료 주문을 지원하는 AI 기반 카페 서비스입니다.

Java 기초 학습 단계의 콘솔 프로그램에서 시작해, 브랜드 랜딩페이지와 예약 · 주문 데모 웹앱으로 이어졌습니다.

원본 저장소: [Binwoojin/aulo-reservation-app](https://github.com/Binwoojin/aulo-reservation-app) (브랜치 `claude/kind-galileo-f34efw`, 커밋 `4ba5be0` 기준으로 옮김)

## 구성

- `java-basic/` — Java 기초 학습 콘솔 프로그램
- `brand-landing/` — 브랜드 랜딩페이지 (정적 HTML/CSS/JS)
- `webapp/` — 공간 추천·예약·음료 주문 데모 웹앱 소스 (React + Vite) → [실행 방법](./webapp/README.md)
- `publishing/` — `webapp/`을 `npm run build`로 만든 정적 빌드 (포트폴리오의 Live Demo)

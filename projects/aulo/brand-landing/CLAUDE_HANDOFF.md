# Claude Code 인계 — Aulo 브랜드 랜딩

## 범위
`index.html`(시맨틱 HTML), `styles.css`(AULO / STYLE BOARD v0.1 토큰 기반 스타일), `script.js`(동적 표현, 점진적 향상)로 구성된다. 폰트(Pretendard·Manrope) 외 외부 라이브러리를 쓰지 않는다. 브라우저에서 바로 열 수 있다.
- 스타일 작업은 UI UX Pro Max 스킬(`.claude/skills/ui-ux-pro-max`)의 접근성·터치·반응형·모션 기준으로 점검했다. 색상·폰트·레이아웃은 스토리보드를 우선했다.
- 확인 완료: 375·390·1280px 가로 스크롤 없음, 텍스트 대비 4.5:1 이상, 칩·컨트롤 테두리 3:1 이상, 터치 영역 44px 이상, sticky 헤더 scroll-padding, reduced-motion.
- 공간 칩은 필터가 아니라 각 공간 카드로 이동하는 앵커다. 네 공간 설명은 항상 모두 보인다.
- 사진: `assets/`의 AI 생성 참고 이미지(flow-cafe·focus·rest·suite, 768/1536px WebP)를 `srcset`으로 사용한다. 히어로는 전용 사진이 없어 Flow Cafe 사진을 세로로 잘라 쓴다. 페이지에 'AI 생성 참고 이미지, 실제 매장 아님' 안내를 둔다. 실제 매장 사진이 생기면 같은 파일명으로 교체한다.

공개 시안: https://raid-insert-58814555.figma.site/
이번 작업에서는 사이트 조회가 완료되지 않아 대화에 첨부된 모바일 전체 페이지·히어로 이미지와 사용자가 확정한 수정 방향을 기준으로 구조를 작성했다. 최신 사이트와 픽셀 단위 일치를 주장하지 않는다.

## 페이지 구조
헤더 → 히어로 → 브랜드 분위기 → 네 가지 공간 → 공용 야외 라운지 안내 → 이용 절차 및 정책 → 서비스 진입 CTA → 푸터.
원 페이지에서 브랜드와 서비스 소개를 완결한다. 회사 소개 페이지를 추가하지 않는다. 예약 화면 구현은 이번 범위에 포함되지 않는다.

## CSS 작업
- 모바일 390px 우선, 좌우 20px 여백. 큰 영문 제목, 얇은 구분선, 넓은 여백으로 따뜻한 미니멀·에디토리얼 분위기 유지.
- 크림 배경 / 차콜 공간 소개 / 올리브 CTA. 기본 참고값: 배경 #F7F4EC, 텍스트 #302B26, 올리브 #596246, 호버 #444D34, 경계 #D8D0C4.
- 한글 Pretendard, 영문 Manrope. 본문 약 16px, 줄 높이 1.5–1.6. 보조 정보 12–14px. 웹앱은 2026-10-20 axe 색 대비 검사 통과(22개 화면, 글자 4.5:1 이상), 입력창 경계는 3:1 이상으로 보정. 브랜드 랜딩은 별도 검수 필요.
- 버튼 높이 48px, 최소 터치 영역 44px. 키보드 포커스, reduced-motion 대응.
- 네 공간 설명은 조작 없이 전부 볼 수 있도록 유지. 가로 슬라이더를 넣더라도 필수 설명을 숨기지 않는다.
- 콘텐츠 높이로 페이지를 구성하고 푸터 아래 긴 빈 공간을 만들지 않는다.
- figure의 `data-asset-slot`은 이미지 자리다. 실제 이미지 확보 시 설명용 figcaption을 적절한 img와 alt로 교체한다. 와이어프레임 스크린샷을 구현 이미지로 쓰지 않는다.
- 기존 원목 사진은 참고 이미지다. Focus는 가림막, Rest는 리클라이너, Suite는 독립된 방이라는 최신 정책과 맞는 사진을 사용한다.

## JavaScript 작업
- 동적 표현 원칙: "Stay in your rhythm" — 느리게 들어오고(640–900ms, ease-out) 짧게 반응한다(180ms, 4px). 장식용 반복 애니메이션은 넣지 않는다.
- 현재 구현: 히어로 1회 등장(문장 순차·사진 아래서 위로 드러남), 섹션 스크롤 등장과 구분선 그리기, 헤더 경계선, 현재 섹션 메뉴 밑줄, 보고 있는 공간 칩 선택 표시(`aria-current="location"`), 카드 hover, 정책 펼침.
- JS가 없거나 `prefers-reduced-motion: reduce`이면 `.motion-ready`가 붙지 않아 모든 내용이 처음부터 보인다.
- 앵커 이동과 details는 기본 HTML로 작동한다. 필요할 때만 JS를 추가한다.
- `data-action="open-service"` 버튼은 현재 비활성이다. 실제 예약 서비스 경로가 준비되면 정상 링크로 교체하고 준비 중 문구를 갱신한다.
- 앱 알림·예약 충돌 검사·음료 혜택 계산은 브랜드 페이지 기능이 아니다. 서비스 구현에서 다룬다.
- 실제 예약처럼 오인되지 않도록 데모 표시 유지. 가격을 온라인 결제금액으로 표시하지 않는다. 방문 후 이용 시작 전 결제다.

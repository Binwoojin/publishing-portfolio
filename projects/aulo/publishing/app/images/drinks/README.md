# 음료 이미지

`webapp/src/config/policy.js`의 MENU 항목 `image`에 적은 이름으로 이 폴더의 사진을 찾는다.
음료 상세(화면 폭), 장바구니(104px), 좌석 추가 주문(56px), 홈 베스트(56px)에 보인다.
사진이 없으면 컵 아이콘 자리표시가 같은 크기로 보인다.

- 파일: `{이름}-400.webp`, `{이름}-1024.webp` 두 장 (정사각형, WebP 품질 80)
- 온도를 고르는 음료(커피 5종·녹차)는 `{메뉴 id}-ice`, `{메뉴 id}-hot` 두 벌을 두고, 고른 온도의 사진이 보인다.
- 한 가지 온도만 있는 음료는 `{메뉴 id}` 한 벌만 둔다.
- 새 사진은 원본(정사각형, 1024px 이상)을 받아 위 규칙으로 변환해 넣는다.

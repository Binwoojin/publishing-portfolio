# 2026-07-28 개발일지

## 오늘의 작업 목표

- 성장 기록에 이미지 및 YouTube 영상 첨부 기능 구현
- 성장 기록 수정·상세 화면의 미디어 처리 개선
- 목표 및 성장 기록 목록 UI 개편
- 전체 페이지 반응형 레이아웃 적용
- 성장 타임라인 화면 프로토타입 제작
- AWS S3 설정과 예외 처리 안정화

## 구현 내용

### 1. 성장 기록 미디어 첨부 기능

성장 기록 작성 시 이미지와 YouTube 영상을 함께 등록할 수 있도록 기능을 확장했다.

- 다중 이미지 업로드 지원
- 성장 기록당 이미지 최대 5장 제한
- JPG, PNG, WEBP 형식만 허용
- 이미지당 최대 5MB 제한
- YouTube 일반 URL, 단축 URL, Shorts URL 처리
- 이미지와 영상의 출력 순서를 `sortOrder`로 관리
- 성장 기록 저장 후 미디어 정보를 함께 저장하도록 서비스 로직 연결

### 2. 성장 기록 수정 기능 개선

기존 성장 기록의 미디어를 유지하면서 새로운 이미지를 추가하거나 기존 미디어를 삭제할 수 있도록 수정 기능을 보완했다.

- 기존 첨부 미디어 목록 조회
- 삭제 예정 미디어 선택 기능
- 기존 이미지와 신규 이미지 합계 검증
- 다른 성장 기록의 미디어가 삭제되지 않도록 소유 관계 검증
- 이미지 삭제 시 S3 객체와 DB 데이터를 함께 제거
- 성장 기록 삭제 시 연결된 미디어도 함께 정리
- 신규 미디어의 정렬 순서를 기존 미디어 다음부터 부여

### 3. 성장 기록 상세 화면 미디어 출력

상세 화면에서 첨부한 이미지와 YouTube 영상을 확인할 수 있도록 구현했다.

- S3 Object Key를 Presigned URL로 변환
- YouTube 영상 ID를 임베드 URL로 변환
- 화면 출력 전용 `MediaResponse` DTO 사용
- 이미지 갤러리 및 YouTube 플레이어 UI 추가
- 이미지 확대 모달과 키보드 접근성 처리

### 4. AWS S3 설정 및 예외 처리 개선

로컬·테스트·배포 환경에서 AWS 자격 증명을 유연하게 사용할 수 있도록 설정을 정리했다.

- 환경변수 기반 Access Key와 Secret Key 지원
- 키가 없을 때 AWS 기본 자격 증명 체인 사용
- 두 키 중 하나만 설정된 경우 애플리케이션 시작 단계에서 오류 처리
- AWS Region을 환경변수로 설정할 수 있도록 변경
- 업로드, 삭제, Presigned URL 생성 오류 메시지 세분화
- AWS SDK 클라이언트 오류와 S3 응답 오류를 구분해 처리
- 이메일 발송 실패 시 내부 오류를 사용자에게 직접 노출하지 않도록 개선

### 5. 성장 기록 목록 UI 개편

기존 카드 목록을 시간의 흐름이 드러나는 타임라인 형태로 개선했다.

- 목표 연동 기록과 자유 기록 필터 제공
- 필터별 표시 개수 동적 갱신
- 필터 결과가 없을 때 빈 상태 화면 출력
- 실제 링크 요소를 사용해 키보드 탐색 및 접근성 개선
- JSP 구조에 컴포넌트 경계를 표시해 향후 React 전환을 고려
- 모바일에서 한 열로 자연스럽게 표시되도록 반응형 처리

### 6. 목표 목록 UI 개선

목표 현황을 빠르게 파악하고 상태별로 조회할 수 있도록 목록 화면을 재구성했다.

- 전체·진행 중·완료 목표 요약 카드 추가
- 목표 상태 필터 기능 구현
- 목표 카드 레이아웃 및 진행률 표현 개선
- 필터 결과가 없는 경우 전용 빈 상태 제공
- 모바일에서 필터를 가로 스크롤로 사용할 수 있도록 처리
- 불필요한 테스트용 콘솔 출력 제거

### 7. 공통 반응형 스타일 적용

페이지별로 흩어진 모바일 보정을 공통 반응형 스타일로 정리했다.

- 태블릿, 모바일, 소형 모바일 구간별 스타일 정의
- 모바일 내비게이션 및 프로필 메뉴 대응
- 목표·기록 작성 폼을 단일 컬럼으로 전환
- 마이페이지, 출석, 설정 화면 레이아웃 보정
- 버튼의 최소 터치 영역 확보
- 모바일 입력창 확대 현상 방지를 위한 폰트 크기 조정
- 가로 스크롤과 콘텐츠 오버플로 방지
- `prefers-reduced-motion` 환경에서 애니메이션 최소화

### 8. 성장 타임라인 프로토타입 제작

목표와 성장 기록을 하나의 여정으로 보여주는 타임라인 화면의 프론트엔드 프로토타입을 추가했다.

- `/timeline` 라우팅 추가
- 로그인하지 않은 사용자의 접근 차단
- 월별 성장 요약 카드 구성
- 성장 기록·목표·마일스톤 유형별 필터 제공
- 월 이동 및 빈 상태 UI 구현
- 향후 서버 데이터 또는 React 컴포넌트로 교체할 수 있도록 구조화

> 현재 타임라인 데이터는 화면 검증을 위한 정적 예시 데이터이며, 실제 데이터 집계는 추후 연결할 예정이다.

### 9. 기타 안정성 개선

- 로그인 상태에 따라 루트 경로의 이동 목적지 분리
- `updatedAt` 컬럼이 실제 수정 시 갱신되도록 매핑 수정
- 엔티티 컬렉션 빌더 기본값 적용
- JPA Open Session in View 비활성화
- 테스트 환경용 H2 의존성과 설정 추가

## 트러블슈팅

### S3 자격 증명 인식 문제

환경마다 AWS 환경변수 이름이 달라 자격 증명을 찾지 못할 가능성이 있었다.

- 프로젝트 전용 환경변수와 AWS 표준 환경변수를 모두 지원하도록 설정했다.
- 명시적인 키가 없으면 AWS SDK의 기본 자격 증명 탐색 방식을 사용하도록 변경했다.

### 수정 시 이미지 개수 초과 문제

새로 선택한 이미지만 검사하면 기존 이미지와 합쳐졌을 때 최대 5장을 초과할 수 있었다.

- 기존 이미지 수에서 삭제 예정 이미지를 제외하고 신규 이미지 수를 더해 최종 개수를 검증하도록 수정했다.

### 미디어 삭제 권한 문제

클라이언트가 다른 기록의 미디어 번호를 전달할 가능성을 고려해야 했다.

- 삭제 대상 미디어가 현재 수정 중인 성장 기록에 속하는지 서버에서 다시 검증하도록 처리했다.

### 사용자에게 내부 오류가 노출되는 문제

이메일 발송 실패 시 예외 메시지가 그대로 응답에 포함되고 있었다.

- 상세 오류는 서버 로그에 남기고 사용자에게는 일반화된 안내 메시지를 반환하도록 변경했다.

## 확인이 필요한 사항

- 새 타임라인 JSP와 일부 공통 반응형 파일에서 한글 인코딩이 깨져 보이는 부분 수정
- 타임라인 JavaScript의 문자열과 마크업 문법 재검증
- 실제 목표·기록 데이터를 이용한 타임라인 집계 로직 연결
- S3 업로드 후 DB 저장 실패 시 보상 삭제가 정상적으로 수행되는지 통합 테스트
- 미디어 수정·삭제 기능에 대한 서비스 테스트 추가
- 모바일 실기기에서 파일 선택 및 이미지 미리보기 확인

## 오늘의 회고

성장 기록을 텍스트 중심 기능에서 이미지와 영상까지 포함하는 형태로 확장했다.  
특히 등록 기능뿐만 아니라 수정·삭제 과정에서 파일과 DB 데이터가 일관되게 관리되도록 검증 로직을 보완했다.

UI 측면에서는 기록과 목표 목록을 단순한 데이터 목록이 아니라 사용자의 성장 흐름이 보이는 구조로 개선했다. 공통 반응형 스타일도 함께 적용해 주요 화면을 모바일에서 사용할 수 있는 기반을 마련했다.

다만 타임라인은 아직 정적 프로토타입 단계이며 일부 파일의 한글 인코딩과 문법을 먼저 정리한 뒤 실제 데이터와 연결해야 한다.

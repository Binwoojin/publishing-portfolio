# 밀스루틴 페르소나별 사용자 시나리오

앞서 정한 세 유형을 바탕으로 작성한 기획 가설입니다.

## 지식 부족형 — 이해하고 시작하기

퇴근 후 집에서 운동을 시작하려던 사용자는 운동 이름부터 낯설어 검색을 망설인다. 홈의 시작 안내를 따라 초급·맨몸 조건으로 운동을 찾아 방법을 살펴본다. 기록을 남기기 위해 가입하고, 신체 정보를 입력한 뒤 ‘운동을 하나씩 알아가기’ 목표를 고른다. 오늘 할 운동과 세트를 직접 구성해 검토하고, 운동 중에는 정해진 목표를 보며 완료한 세트를 체크한다. 결과를 저장한 후 대시보드와 운동 기록에서 첫 실천이 남았음을 확인한다.

상황: 운동 용어와 세트·횟수가 낯선 신규 사용자. 퇴근 후 집에서 할 수 있는 운동을 찾으며 처음 방문한다.

목표: 운동 방법을 이해하고 오늘의 첫 기록을 남긴다.

1. **찾아보기** — 초급·맨몸 조건으로 운동을 찾아 방법을 확인한다. / H01 → E01 → E02
2. **준비하기** — 무료 가입·설문 후 키·몸무게와 운동 목표를 설정한다. / A03 → A02 → H01 → P06 / W01-1
3. **구성하기** — 오늘 날짜를 정하고 운동을 추가해 세트를 검토한다. / W10 → W12 → W02 → W13 → W11
4. **실행하기** — 목표 횟수를 보며 운동하고 세트 완료를 누른다. / W14-2
5. **확인하기** — 결과를 저장하고 오늘 기록을 다시 확인한다. / W15-1 → W01 → W10

완료 결과: 처음 고른 운동을 수행하고 저장된 결과를 다시 찾는다.

예외: 운동 검색 결과가 없으면 조건을 바꾼다. 신체 정보 입력을 미루면 홈 배너로 다시 진입한다.

검증: 운동 방법과 세트 목표를 이해했는지, 저장한 기록을 스스로 다시 찾는지 확인한다.

## 실천 제약형 — 준비 시간을 줄이기

사용자는 짧은 여유 시간에 다음 날 운동을 미리 준비하려 한다. AI 운동 플랜 안내를 보고 가능한 난이도·부위·도구와 휴식 포함 시간 조건을 고른다. 추천 결과를 확인하고 내일 목록으로 등록한다. 다음 날 준비해 둔 목록을 열어 운동을 진행하므로 다시 검색할 필요가 없다. 점심 기록은 식단 화면의 즐겨찾기 음식에서 양과 끼니를 확인해 저장한다. 아직 먹지 않은 저녁은 비워 두고, 실제로 한 운동과 먹은 식사만 기록으로 남긴다.

상황: 일정이 자주 바뀌는 기존 회원. 잠깐 난 여유에 내일 할 운동을 준비하고 오늘 먹은 점심도 기록하려 한다.

목표: 가능한 조건으로 운동을 준비하고 식단 기록을 빠르게 끝낸다.

1. **조건 고르기** — AI 안내 후 난이도·부위·도구·시간을 선택한다. / I01 → I02 → I02-1
2. **내일 준비** — 추천 구성을 검토한 뒤 내일 목록으로 등록한다. / I02-1 → W10 / W11
3. **목록 실행** — 다음 날 오늘이 된 목록에서 운동을 시작한다. / W10 → W11 → W14-1~3
4. **빠른 식사 기록** — 즐겨찾기 음식을 선택하고 점심·먹은 양을 확인한다. / D01 → P07 → D02
5. **실제만 저장** — 오늘 먹은 점심을 저장하고 끼니 기록을 확인한다. / D02 → D01 → D01-2

완료 결과: 운동 준비와 반복 검색 부담을 줄이고 실제 식사 기록을 남긴다.

예외: AI 체험을 다 썼다면 직접 구성으로 전환한다. 분석 완료 전에 취소하면 체험을 차감하지 않는다.

검증: 추천 등록 날짜를 구분하는지, 즐겨찾기로 선택한 음식의 양·끼니를 정확히 저장하는지 확인한다.

## 지속 실패형 — 끊겨도 이어가기

오랜만에 돌아온 사용자는 이전 목록과 저장해 둔 루틴을 보며 자신이 했던 운동을 떠올린다. 부담스러운 목표는 다시 설정하고, 익숙한 루틴을 오늘 가능한 세트 수로 줄여 준비한다. 운동 중 갑자기 일이 생기면 현재 시안 세션에서 진행을 멈췄다가 이어 간다. 끝까지 마치지 못한 날에도 완료한 세트만 결과로 저장하고 전체 완료와 구분해 확인한다. 이후 기본 주간 리포트로 기록 흐름을 돌아보며 다음 실천을 준비한다.

상황: 목표를 크게 세웠다가 일정이 깨지면 기록을 중단하는 재방문 사용자. 예전 목표를 그대로 이어가기에는 부담을 느낀다.

목표: 기존 기록을 유지하면서 오늘 가능한 분량으로 다시 시작한다.

1. **지난 실천 보기** — 이전 운동 목록과 기록에서 해 봤던 운동을 확인한다. / W01 → W10 → W16
2. **부담 낮추기** — 운동 목표를 현재 가능한 수준으로 다시 정한다. / W01 → W01-1 → W01
3. **익숙하게 준비** — 내 루틴을 열고 오늘 할 운동량을 조정한다. / W06 → W07 → W02 → W11
4. **한 만큼 남기기** — 운동을 진행하고 완료한 세트의 결과를 저장한다. / W14-1~3 → W15 / W15-1
5. **다음 실천 잇기** — 기본 주간 리포트를 보고 다음 목록을 준비한다. / W01 → I05 → I05-1 / W10

완료 결과: 기록을 지우지 않고 수행량을 조정해 새로운 실제 기록을 남긴다.

예외: 루틴이 없다면 직접 목록을 구성한다. 일부만 수행했다면 전체 완료로 표시하지 않고 부분 결과를 확인한다.

검증: 기존 기록 보존·목표 변경·부분 수행 기록의 차이를 이해하는지, 재방문에 부담을 느끼는 표현은 없는지 확인한다.

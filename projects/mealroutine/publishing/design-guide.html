03 / DASHBOARD DESIGN

카드로 요약하고, 그래프로 흐름을 읽습니다.

운동·식단 대시보드는 오늘의 현황 → 주간 흐름 → 기록 행동 순서로 구성합니다. 카드와 그래프의 역할을 나누어 필요한 정보를 빠르게 찾도록 합니다.

대시보드 예시 선택
  • 01 · 요약 카드는 핵심 수치부터

    제목 → 큰 수치·단위 → 목표 대비 진행률 → 기록 요약 순서로 읽습니다. 오늘 실제 기록과 내일 계획은 별도 탭으로 구분합니다.

  • 02 · 카드는 정보 묶음 단위로

    오늘 요약과 주간 추이를 흰 카드로 분리합니다. 모서리 12px·1px 경계·16px 안쪽 여백을 사용하고 강한 그림자는 줄입니다.

  • 03 · 그래프는 비교 목적에 맞게

    첫 화면은 오늘 수치와 목표 대비 가로 막대, 다음은 일주일 세로 막대, 마지막은 구성 비율 파이입니다. 3개 화면이 순환하며 미기록은 0과 구분합니다.

  • 04 · 색상과 동작은 일관되게

    운동은 인디고, 식단은 오렌지를 버튼과 그래프에 적용합니다. 수치와 막대는 함께 등장하며 모션 줄이기 설정에서는 즉시 표시합니다.

왜 이 조합이 기준을 충족하나요?
각 행의 대비값이 일반 텍스트 기준 4.5 이상이기 때문입니다. ‘진한 블루라서’처럼 인상으로 판정하지 않고, 실제 CSS의 글자색과 바탕색을 수치로 비교합니다. 표시값은 소수 둘째 자리까지 보여주지만 통과 여부는 반올림 전 값으로 판단합니다. 4.499는 통과가 아닙니다.
계산식
CONTRAST RATIO · 명암 대비 계산식대비 = (밝은 쪽 휘도 + 0.05) / (어두운 쪽 휘도 + 0.05)
HEX의 RGB를 각각 0~1의 sRGB 값으로 바꿉니다. 각 값 c가 0.04045 이하이면 c / 12.92, 그보다 크면 ((c + 0.055) / 1.055)2.4로 선형화합니다. 상대 휘도 L은 0.2126R + 0.7152G + 0.0722B로 계산합니다. 이 페이지의 표도 같은 함수로 산출합니다.
어떤 기준을 적용하나요?
  • 일반 텍스트는 4.5:1 이상. 이 가이드의 본문·보조 글자는 모두 이 기준으로 봅니다.
  • 큰 글자는 3:1 이상 기준을 적용할 수 있습니다. 기준 크기는 일반 24 CSS px 이상 또는 굵은 글자 약 18.67 CSS px 이상입니다. 글꼴·굵기를 임의로 큰 글자로 간주하지 않습니다.
  • 컨트롤 식별과 중요한 상태 표시에 필요한 비텍스트 요소는 인접 색과 3:1 이상을 확인합니다. 모든 장식용 구분선에 이 조건을 일괄 적용하는 것은 아닙니다.
구현 시 다시 확인할 부분
  • text-muted/50 같은 투명도, 반투명 배경, 이미지·그라디언트 위 글자는 합성된 실제 배경색으로 다시 검증합니다.
  • 호버·선택·포커스·오류·플레이스홀더는 실제 사용 조합을 따로 확인합니다. 현재 표의 다섯 조합 통과가 전체 페이지의 접근성 인증을 의미하지 않습니다.
  • 페이퍼로지의 작은 글자나 가는 획은 수치가 통과해도 읽기 어려울 수 있습니다. 본문 크기·굵기·줄 간격과 실제 화면을 함께 확인합니다.
  • 운동·식단·오류를 색상만으로 구분하지 않고 이름·아이콘·설명을 함께 제공합니다.
